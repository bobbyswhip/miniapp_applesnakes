# Token Wars X402 Frontend Implementation Guide

## Problem Analysis

The error `X-PAYMENT header is required` with a 402 status is **correct behavior**. This is the x402 protocol working as intended:

1. Frontend makes initial POST request (no payment)
2. Server returns 402 with payment requirements in `accepts` array
3. **MISSING STEP**: Frontend must parse requirements, sign EIP-3009, and retry
4. Frontend retries request WITH X-PAYMENT header
5. Server processes payment and returns success

Your frontend is treating the 402 as an error instead of handling it as the first step in a two-step payment flow.

## Complete Working Implementation

### useTokenWarsBuy.ts - Complete Hook

```typescript
/**
 * useTokenWarsBuy - X402 Payment Hook for Token Wars
 *
 * Handles the complete x402 payment flow:
 * 1. Initial request → 402 response with payment requirements
 * 2. Parse requirements from accepts array
 * 3. Sign EIP-3009 TransferWithAuthorization with wallet
 * 4. Retry request with X-PAYMENT header
 * 5. Process success/error response
 */

import { useState, useCallback } from 'react';
import { useAccount, useWalletClient } from 'wagmi';

// =============================================================================
// Types
// =============================================================================

export interface PaymentRequirements {
  scheme: string;
  network: string;
  maxAmountRequired: string;
  resource: string;
  description?: string;
  payTo: string;
  maxTimeoutSeconds?: number;
  asset?: string;
}

export interface BuyResult {
  success: boolean;
  message?: string;
  buy?: {
    warId: string;
    amount: number;
    txHash: string;
    wallet: string;
    timestamp: number;
    dexVote: string;
    pairVote: string;
  };
  war?: {
    id: string;
    name: string;
    symbol: string;
    totalRaised: number;
    participantCount: number;
    endsAt: number;
  };
  wallet?: {
    totalContribution: number;
    sharePercent: number;
  };
  consensus?: {
    dex: {
      leading: string;
      v4: { votes: number; percent: number };
      aerodrome: { votes: number; percent: number };
      hydrex: { votes: number; percent: number };
    };
    pair: {
      leading: string;
      eth: { votes: number; percent: number };
      wass: { votes: number; percent: number };
    };
  };
  error?: string;
}

export type BuyStatus =
  | 'idle'
  | 'requesting'
  | 'signing'
  | 'processing'
  | 'success'
  | 'error';

// =============================================================================
// Constants
// =============================================================================

const API_BASE = 'https://api.applesnakes.com';
const USDC_ADDRESS = '0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913';
const USDC_DECIMALS = 6;
const SIGN_TIMEOUT = 60000; // 60 seconds

// EIP-712 domain for USDC on Base
const USDC_DOMAIN = {
  name: 'USD Coin',
  version: '2',
  chainId: 8453,
  verifyingContract: USDC_ADDRESS,
} as const;

// EIP-3009 TransferWithAuthorization types
const TRANSFER_AUTHORIZATION_TYPES = {
  TransferWithAuthorization: [
    { name: 'from', type: 'address' },
    { name: 'to', type: 'address' },
    { name: 'value', type: 'uint256' },
    { name: 'validAfter', type: 'uint256' },
    { name: 'validBefore', type: 'uint256' },
    { name: 'nonce', type: 'bytes32' },
  ],
} as const;

// =============================================================================
// Utilities
// =============================================================================

function generateNonce(): `0x${string}` {
  const bytes = new Uint8Array(32);
  crypto.getRandomValues(bytes);
  return ('0x' + Array.from(bytes).map(b => b.toString(16).padStart(2, '0')).join('')) as `0x${string}`;
}

// =============================================================================
// Hook Implementation
// =============================================================================

export function useTokenWarsBuy() {
  const { address, isConnected } = useAccount();
  const { data: walletClient } = useWalletClient();

  const [status, setStatus] = useState<BuyStatus>('idle');
  const [error, setError] = useState<string | null>(null);
  const [result, setResult] = useState<BuyResult | null>(null);

  /**
   * Create the X-PAYMENT header from payment requirements
   */
  const createPaymentHeader = useCallback(async (
    accepts: PaymentRequirements,
    amountUSDC: number
  ): Promise<string> => {
    if (!walletClient || !address) {
      throw new Error('Wallet not connected');
    }

    console.log('[TokenWarsBuy] Creating payment header for $' + amountUSDC);

    // Calculate amount in atomic units (6 decimals for USDC)
    const amountInAtomicUnits = BigInt(Math.floor(amountUSDC * 10 ** USDC_DECIMALS));

    const nonce = generateNonce();
    const now = Math.floor(Date.now() / 1000);
    const validAfter = BigInt(0);
    const validBefore = BigInt(now + (accepts.maxTimeoutSeconds || 3600));

    const message = {
      from: address as `0x${string}`,
      to: accepts.payTo as `0x${string}`,
      value: amountInAtomicUnits,
      validAfter,
      validBefore,
      nonce,
    };

    console.log('[TokenWarsBuy] Signing message:', {
      from: message.from,
      to: message.to,
      value: amountInAtomicUnits.toString(),
      nonce,
    });

    // Sign with timeout
    const signPromise = walletClient.signTypedData({
      account: walletClient.account!,
      domain: USDC_DOMAIN,
      types: TRANSFER_AUTHORIZATION_TYPES,
      primaryType: 'TransferWithAuthorization',
      message,
    });

    const timeoutPromise = new Promise<never>((_, reject) => {
      setTimeout(() => reject(new Error('Wallet signing timed out')), SIGN_TIMEOUT);
    });

    const signature = await Promise.race([signPromise, timeoutPromise]);
    console.log('[TokenWarsBuy] Signature obtained');

    // Build authorization object
    const authorization = {
      from: address,
      to: accepts.payTo,
      value: amountInAtomicUnits.toString(),
      validAfter: '0',
      validBefore: validBefore.toString(),
      nonce,
    };

    // Create x402 payment payload
    const payload = {
      x402Version: 1,
      scheme: 'exact',
      network: 'base',
      payload: {
        signature,
        authorization,
      },
    };

    console.log('[TokenWarsBuy] Payment header created');
    return btoa(JSON.stringify(payload));
  }, [walletClient, address]);

  /**
   * Execute the buy with x402 payment
   */
  const buyIn = useCallback(async (
    warId: string,
    amountUSDC: number,
    dexVote: 'v4' | 'aerodrome' | 'hydrex',
    pairVote: 'eth' | 'wass'
  ): Promise<BuyResult> => {
    if (!isConnected || !walletClient || !address) {
      const err = { success: false, error: 'Wallet not connected' };
      setError(err.error);
      setStatus('error');
      return err;
    }

    if (amountUSDC < 1 || amountUSDC > 10000) {
      const err = { success: false, error: 'Amount must be between $1 and $10,000' };
      setError(err.error);
      setStatus('error');
      return err;
    }

    setStatus('requesting');
    setError(null);
    setResult(null);

    const requestBody = JSON.stringify({ warId, dexVote, pairVote });
    const endpoint = `${API_BASE}/api/token-wars/buy`;

    try {
      // =========================================================================
      // STEP 1: Initial request to get payment requirements
      // =========================================================================
      console.log('[TokenWarsBuy] Step 1: Making initial request...');

      const initialResponse = await fetch(endpoint, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: requestBody,
      });

      console.log('[TokenWarsBuy] Initial response status:', initialResponse.status);

      // If not 402, either success or error
      if (initialResponse.status !== 402) {
        const data = await initialResponse.json();
        if (data.success) {
          setResult(data);
          setStatus('success');
          return data;
        } else {
          throw new Error(data.error || 'Request failed');
        }
      }

      // =========================================================================
      // STEP 2: Parse payment requirements from 402 response
      // =========================================================================
      console.log('[TokenWarsBuy] Step 2: Parsing payment requirements...');

      const paymentData = await initialResponse.json();
      console.log('[TokenWarsBuy] Payment requirements:', paymentData);

      const accepts = paymentData.accepts?.[0] as PaymentRequirements;
      if (!accepts) {
        throw new Error('Invalid payment requirements from server');
      }

      console.log('[TokenWarsBuy] Payment info:', {
        payTo: accepts.payTo,
        minAmount: accepts.maxAmountRequired,
        network: accepts.network,
      });

      // =========================================================================
      // STEP 3: Sign EIP-3009 TransferWithAuthorization
      // =========================================================================
      console.log('[TokenWarsBuy] Step 3: Signing payment...');
      setStatus('signing');

      const paymentHeader = await createPaymentHeader(accepts, amountUSDC);

      // =========================================================================
      // STEP 4: Retry request with X-PAYMENT header
      // =========================================================================
      console.log('[TokenWarsBuy] Step 4: Submitting payment...');
      setStatus('processing');

      const paidResponse = await fetch(endpoint, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'X-PAYMENT': paymentHeader,
        },
        body: requestBody,
      });

      const result = await paidResponse.json();
      console.log('[TokenWarsBuy] Final response:', result);

      // =========================================================================
      // STEP 5: Handle response
      // =========================================================================
      if (result.success) {
        setResult(result);
        setStatus('success');
        return result;
      } else {
        throw new Error(result.error || 'Payment failed');
      }

    } catch (err) {
      const message = err instanceof Error ? err.message : 'Buy failed';
      console.error('[TokenWarsBuy] Error:', message);
      setError(message);
      setStatus('error');
      return { success: false, error: message };
    }
  }, [isConnected, walletClient, address, createPaymentHeader]);

  /**
   * Reset the hook state
   */
  const reset = useCallback(() => {
    setStatus('idle');
    setError(null);
    setResult(null);
  }, []);

  return {
    // State
    status,
    error,
    result,
    isConnected,
    address,

    // Actions
    buyIn,
    reset,

    // Computed
    isLoading: ['requesting', 'signing', 'processing'].includes(status),
    isSuccess: status === 'success',
    isError: status === 'error',
  };
}

export default useTokenWarsBuy;
```

## X-PAYMENT Header Structure

The X-PAYMENT header is a base64-encoded JSON object:

```javascript
// Decoded structure:
{
  "x402Version": 1,
  "scheme": "exact",
  "network": "base",
  "payload": {
    "signature": "0x...",  // EIP-712 signature
    "authorization": {
      "from": "0xUserWallet...",      // User's wallet
      "to": "0xE5e91...",             // AI Wallet (payTo)
      "value": "5000000",             // $5 in atomic units
      "validAfter": "0",
      "validBefore": "1734200000",    // Unix timestamp
      "nonce": "0x..."                // Random 32-byte nonce
    }
  }
}
```

## Common Errors and Solutions

### Error: "X-PAYMENT header is required"
**Cause**: Frontend is not handling the 402 response
**Solution**: Implement the two-step flow - receive 402, sign payment, retry with header

### Error: "User rejected the signature request"
**Cause**: User clicked Cancel in wallet popup
**Solution**: Show clear message asking user to try again and approve signature

### Error: "Wallet signing timed out"
**Cause**: Wallet popup didn't respond in 60 seconds
**Solution**: Ask user to disconnect/reconnect wallet and try again

### Error: "Insufficient USDC balance"
**Cause**: User doesn't have enough USDC
**Solution**: Show balance check before buy, link to swap for USDC

### Error: "Payment was not accepted"
**Cause**: Signature invalid or already used
**Solution**: Ensure fresh nonce, correct chain ID (8453 for Base)
